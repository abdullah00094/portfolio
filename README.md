# Abdullah Ibraheem — Portfolio

An evidence-led portfolio for a Technical Product Owner and Laravel Backend Engineer building AI-powered automation.

## Local development

Run `npm install`, then `npm run dev`. Production checks are `npm run lint` and `npm run build`.

Content is centralized in `app/content/`. Project detail routes are generated from `app/content/projects.js`; the printable CV also consumes the shared content.

The visual system uses a technical dossier aesthetic with editorial typography, warm paper, ink, and chartreuse. Company projects are explicitly marked confidential and use sanitized workflow diagrams.
